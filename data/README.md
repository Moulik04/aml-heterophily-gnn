# Data

## IBM AML HI-Medium

Download from Kaggle:  
https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml

Place the downloaded files in this directory:
data/ibm/HI-Medium_Trans.csv

This project uses the HI-Medium split (2,000,000 transactions).

## Elliptic Bitcoin Dataset

Download from Kaggle:  
https://www.kaggle.com/datasets/ellipticco/elliptic-data-set

Place the downloaded files in:
data/elliptic/elliptic_txs_features.csv
data/elliptic/elliptic_txs_edgelist.csv
data/elliptic/elliptic_txs_classes.csv

Neither dataset is included in this repository due to size and licensing.
